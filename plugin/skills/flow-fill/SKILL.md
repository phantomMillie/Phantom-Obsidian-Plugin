# 밀리 플로우 2단계 — 🧐 채우기

경로는 `~/.millie-obsidian/config.json` 에서 읽는다 — `vault` 와 `paths`(vault 기준 상대 경로).
본문의 `<키>` = `<vault>/<paths.키>`. 설정에 없는 키는 사용자에게 묻는다.

정책을 정하는 건 사용자다. 나는 **받아 적고 두 곳을 맞춘다.**

## 1. 대상

- 인자로 문서 경로. 없으면 `🧭` / `📥` 소스 플로우 중 🧐 남은 문서 목록을 보여주고 묻는다
- 남은 🧐 를 문서 순서대로 번호 매겨 보여준다 — 위치(섹션·노드) + 한 줄

## 2. 한 번에 한 분기

- 사용자가 던지는 순서대로. 여러 개를 한꺼번에 받아도 하나씩 반영하고 확인
- 출처를 같이 받는다 — 회의록 전체 경로 / 설계 문서 링크 · ID. 없으면 `구두 확정 <오늘>`
- 받은 정책을 일반화·확장하지 않는다. 다른 🧐 에도 적용될 것 같으면 **묻는다**

## 3. 반영 — 두 곳 동시에

- 본문: 🧐 노드 → 동작 라벨로 교체, `unsure` class 제거 (🟧면 `tobe` 유지)
- `📌 미확정 항목` 의 해당 줄 → 바로 아래 `## ✅ 확정 (🧐 채움)` 으로 이동, 끝에 `— <출처>`
- 채운 결과 새 분기가 생기면 그 분기는 **새 🧐** 로 그린다. 추측으로 이어 그리지 않는다

## 4. 검사

- [ ] 본문 🧐 수 = `📌 미확정 항목` 수
- [ ] 이번에 채운 항목마다 출처 있음

남은 🧐 가 0이면 `qa-promote` 스킬을 제안한다.
