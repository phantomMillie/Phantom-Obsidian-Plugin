# TODO Pile

할 일이 블록이 되어 바탕화면(폴더 아이콘 위, 앱 창 아래)에 떨어지고, 물리 엔진(SpriteKit)으로 기울고 구르며 쌓인다.

- 할 일 = 둥근 글자 카드(프로젝트마다 한 색 — 새 프로젝트는 이미 쓰는 색들과 색상환에서 가장 먼 색, 빨강 근처는 경고용으로 비움, 한 번 정하면 state 에 남아 안 바뀜. Jira 도 프로젝트 키별로, 아랫줄에 프로젝트 · 묵은 날 · 마감). 길면 줄을 바꿔 카드가 커진다. 급할수록(오래됨 · 마감 · 중요도 · 미룸) 글자가 커진다
- 마감 당일 · 지남은 빨간 배지(`오늘` · `D+3`)와 빨간 테두리. 카드는 30도 넘게 안 넘어가 늘 읽힌다
- 메아리 = 글자 없는 작은 블록. 마감 지나면 하루마다 3개(최대 30), 아니면 열흘마다 1개(최대 8). 화면 80%가 차면 메아리는 건너뛴다
- **왼쪽 클릭** = 잡고 끌기(놓으면 던져진다, 다른 블록을 밀어낸다). **오른쪽 클릭** = Claude 로 해결하기 · AI 로 수정하기 · 완료 · 마감·중요도 정하기 · 버리기 · 코드 폴더 바꾸기
- Claude 로 해결하기: 모델을 고르고(엔터 = Opus · Sonnet · Haiku · Esc 취소) 프로젝트의 코드 폴더(처음 한 번 고르면 기억)에서 Ghostty 보통 창으로 `claude` 를 열고 할 일을 첫 메시지로 넘긴다
- AI 로 수정하기: vault 에서 Ghostty 보통 창으로 `claude --model sonnet` 을 열고 `"<할 일>" 항목 수정할거야. 수정사항은 다음 답변에서 줄게.` + TODO 파일 · 원래 줄을 첫 메시지로 보낸다
- 블록 밖 클릭은 바탕화면으로 통과한다. 끝낸 할 일의 카드는 빠지고 위가 무너져 내려앉는다. 새 할 일은 위에서 떨어진다
- **Jira**: 메뉴바 `Jira 연결…` 에서 사이트 · 이메일 · API 토큰을 넣으면(토큰은 키체인) 10분마다 `assignee = currentUser() AND statusCategory != Done` 을 가져와 Jira 파란 블록으로 떨어뜨린다. Jira 에서 끝내면 블록이 빠진다. 오른쪽 클릭 = Jira 에서 열기 · Claude 로 해결하기. 마감 지난 이슈만 메아리가 쌓인다
- **도구 블록** (흰색, 늘 더미 위에 얹힘): `＋ 할 일 쓰기` 클릭 = 할 일 추가 창(중 · 반나절 · 3일 뒤가 미리 골라져 있어 내용만 쓰고 엔터), `🎙 회의하기` 클릭 = 회의 창 — 카테고리 · 종류 · 참석자 · 안건 · 내용 · 결정 사항 + 녹음(m4a). 저장하면 회의 템플릿과 같은 자리(`01. Meeting/<카테고리>/<날짜>.md`)에, 녹음은 `녹음/` 에 넣고 노트에 붙인다. `저장하고 Claude 로 정리` 는 vault 에서 Claude 를 열어 회의록을 다듬고 할 일을 뽑는다. 녹음 권한 설명은 `Info.plist` 를 실행 파일에 넣어 둔다
- **메뉴바 `TODO`** = 바탕화면에 블록 보이기(켜고 끄기) · 할 일 추가 · 새로고침(다시 읽고 블록을 처음부터 다시 떨어뜨림)(내용·프로젝트·중요도·마감·난이도 필수) · 급한 순 할 일 목록(항목마다 위와 같은 동작)
- 다 쌓이면 그리기를 멈춘다(CPU 0). 날이 바뀌면 처음부터 다시 쌓는다
- 읽고 쓰는 곳: vault 최신 `3. Resources/07. TODO/YYYY-MM-DD.md` — `- [ ] 🔸 [프로젝트] 내용 · ❗상 · 📅 2026-10-20 · ↻1`. 3초마다 바뀌었는지 보고 바뀌면 바로 반영한다
- 설정: `~/.phantom-obsidian/state/todo-pile.json` (보이기 · 프로젝트별 코드 폴더)
- 설치 `./install.sh` · 제거 `./install.sh --uninstall` · 시험 `PILE_SCREEN=1 PILE_TEST_CLOSE=40 bin/todo-pile` (그 모니터 앱 창 위에 40초)
